Core Features

覆盖进销存全链路的核心能力

从采购申请到科室领用，从批次效期到精细权限，MediStock Pro 将医院物资流转的每一个环节都纳入闭环管控。

全链路闭环

采购申请 → 订单 → 到货 → 验收 → 入库；科室申领 → 审批 → 锁定 → 拣货 → 复核 → 签收 → 红冲，全程留痕可追溯。

采购入库 科室领用 红冲回退

批次效期管理

库存精确到批次，FEFO 先效期先出自动推荐；近效期 / 已过期分级预警，问题批次可冻结封存。

FEFO 推荐 分级预警 冻结封存

精细化权限

75 个功能权限点 + 15 菜单分组 RBAC，叠加全部数据 / 按仓库 / 本机构三级数据范围，权限精确到按钮。

75 权限点 三级数据范围 按钮级

采购全链路

采购申请 → 审批 → 转订单 → 订单审批 → 到货 → 验收 → 入库；采购协议生效 / 终止、供应商报价与资质管理。

协议管理 供应商资质 报价管理

管理驾驶舱

库存总值、在库总量、可用 / 锁定 / 在途结构、近 7 日出入库趋势、待办审批一屏汇总，决策有据可依。

一屏总览 趋势可视化 待办驱动

1

四级组织树 + 仓库行级数据隔离

支持集团 / 医院 / 院区 / 科室组织层级，库存数据按仓库行级隔离，同一物资不同仓库独立管控，满足多院区与多仓协同。

2

Flyway 数据库版本化 + 开箱即用演示数据

启动自动建表 + 初始化完整演示数据（物资 / 供应商 / 库存批次 / 各类单据），零配置体验全流程，便于学习、演示与二次开发。

3

v-permission 指令级权限控制

前端 75 个权限点 + 按钮级 v-permission 指令 + 路由守卫 + 菜单过滤四层联动，后端接口 + 数据范围双重校验，安全不留死角。

Use Cases

面向真实医疗业务场景

从三甲医院设备科到基层卫生机构，从药房到医药流通企业仓库，MediStock Pro 适配多类医疗物资管理需求。

SCENE / 01

医院设备科耗材管理

适用：设备科 / 耗材库管理员

解决耗材批号效期追踪困难、科室申领审批链路过长、库存盘点差异难溯源等设备科典型痛点。

  • 批次批号 + 效期一体追溯，问题耗材一键召回
  • 多级审批可配置，申领流程在线闭环
  • 盘点差异自动比对，账实相符率显著提升

SCENE / 02

药房药品库存管控

适用：药剂科 / 药房

解决药品 FEFO 先效期先出执行难、近效期预警滞后、处方与库存难以联动等药房管理难题。

  • FEFO 自动推荐出库批次，杜绝过期损耗
  • 近效期分级预警，临期药品优先调剂
  • 处方开具与实时库存联动，缺药即时提示

SCENE / 03

基层医疗机构物资管理

适用：社区卫生服务中心 / 乡镇卫生院

解决物资品类繁多但人手不足、采购合规要求高、报表统计费时等基层机构常见问题。

  • 低门槛开箱即用，一套系统覆盖全品类
  • 采购合规流程内置，审批留痕可审计
  • 收发存报表自动生成，盘点一键导出

医药流通企业仓库

适用：医药商业公司内部仓库

解决多仓库调拨协同、供应商报价管理分散、收发存报表口径不统一等流通企业仓库难题。

About

关于项目

MediStock Pro 由 coderoadmap.cn 团队发起，开源动机源于一线医疗物资管理的真实痛点。

项目定位

一套覆盖医院采购、库存、领用、核算全链路的开源进销存系统，强调批次效期、精细化权限与多组织数据隔离，可作为生产系统也可作为学习范例。

开源动机

医疗物资管理专业性强、门槛高，市面方案要么过于昂贵、要么不够专业。我们希望以开源 + 商业授权的方式，让优质方案触手可及，同时维持长期演进。
